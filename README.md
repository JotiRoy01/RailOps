# RailOps
Designed and developed a modular railway operations platform using React, Spring Boot and PostgreSQL, implementing concurrency-safe ticket reservation, RBAC, real-time train tracking, operational workflows, event-driven notifications, maintenance management and AI-assisted operational search.


# create a Vite + React + TypeScript
```bash
cd path/to/RailOps
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install
npm run dev
```
